# 1.8.0

**本次为合并版**：以社区版 1.7.14 为底座，并入自有分支 1.3.2 的独有能力。包名仍为 `dsh-purge-community`，内部 Cordis id 仍为 `dsh-purge`，HTTP 路由 `/dsh-purge/*` 与用户数据目录不变。

## 新增（取自自有分支 1.3.2）

- **拒答治理两层**：`refusal`（判据）+ `refusal-prefix`（`llm/stream` 开头命中拒绝即掐断重跑，默认 400 字符窗口）。与社区版 `refusal-retry` 互斥：`refusalPrefix` 默认开，此时社区版那条不接管；要换成社区版实现，把 `refusalPrefix` 置 false。
- **会话保活**：`session-guard`（step 编号守卫）+ `session-repair`（断裂会话修复），新增 `purge-sessions` 命令。
- **审批接管**：`approval-takeover`（不依赖宿主静态改写的审批服务接管）+ `subagent-control`（子代理 approval/policy 翻 ask 并放行）。
- **尾部锚点**：`anchor` + `reanchor`，`anchorMode: tail|off`；`identity.js` 新增 `anchorText` 通道（社区版原来 `anchorApplied` 是硬编码 false）。新增 `purge-anchor` 命令。
- **装配清洗**：`assemble-scrub`，接入装配瀑布入口。
- **模型调优**：`model-tuning`，按模型点名补丁。
- **Web / 二进制前置**：`web-preflight-entry` + `web-reclaim`（进程/端口回收，补 `restart-web` 的 `waitFree` 兜底）、`bin-preflight`（宿主 bin 启动前置检查）。
- **预设默认**：`preset-default`，卸载时调 `clearOwnedSelectedDefault`。
- **补丁 #18 / #19**：`REPEAT_TOOL_REMINDER_DISABLED`、`TOOL_RESULT_PRUNER_DISABLED`。社区版 id 序列中 18/19 空缺，直接沿用原号。
- **补丁 #97**：`DESKTOP_HOST_SIGNAL_EXIT_LOG`，收进新建的 `lib/patches/legacy.mjs`，标记 `obsolete: true`。自有版此补丁原编号 #91，与社区版 #91 `BROWSER_COOKIE_NAME_IGNORE_PORT` 同号不同物，故改号。

补丁总数 88 → **89 条**（`ALL_PATCHES` 汇总）。
